Execute o workflow "Página de curso".

Leia contexto/ufape-geral.md, o contexto da linha e contexto/catalogo-de-cursos.md antes de começar. Linha e curso deste pedido: $ARGUMENTS

1. Use o agente pesquisa-de-palavras-chave para produzir a palavra-chave principal e as secundárias da página. Salve e passe o arquivo para a próxima etapa.
2. Use o agente mensagens para produzir a mensagem central do curso e as respostas às 3 principais objeções. Salve e passe o arquivo para a próxima etapa.
3. Use o agente landing-page para produzir a copy completa da página, com todos os dados de curso vindos do catálogo. Salve e passe o arquivo para a próxima etapa.
4. Use o agente seo-on-page para produzir o título, a descrição, os intertítulos e os links internos otimizados. Salve e passe o arquivo para a próxima etapa.
5. Use o agente otimizador-de-cta para produzir as chamadas e o formulário de inscrição. Salve e passe o arquivo para a próxima etapa.
6. Use o agente qa-de-marketing para rodar auditorias/03-busca.md, auditorias/08-conversao.md e auditorias/conformidade-educacional.md.

Pare depois de cada etapa, mostre a saída e espere minha aprovação.
Concluído quando: copy aprovada e entregue para publicação no site, com o rastreamento definido.
