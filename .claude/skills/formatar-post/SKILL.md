# Formatar um post para leitura rápida

Propósito: deixar qualquer post fácil de ler no celular, onde candidatos e alunos consomem quase todo o conteúdo.

Passos:
1. Coloque o gancho sozinho na linha 1.
2. Quebre o texto em linhas curtas, com espaço em branco.
3. Uma ideia por linha ou por item de lista.
4. Termine com um ponto claro ou uma pergunta (por exemplo: "Qual curso você está em dúvida?").
5. Confira se as 3 primeiras linhas funcionam bem sozinhas.

Saída: post formatado.

Verificações antes de terminar:
- Nenhum parágrafo passa de 3 linhas.
- As 3 primeiras linhas fazem sentido sozinhas.
