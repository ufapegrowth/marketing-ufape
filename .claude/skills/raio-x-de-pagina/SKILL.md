# Raio-x de uma landing page de curso

Propósito: Encontrar o que impede o visitante de se inscrever ou falar com o time de captação.

Passos:
1. Faça o teste dos 5 segundos no topo da página (que curso, para quem, qual modalidade, o que fazer agora), no celular.
2. Liste os pontos de atrito: formulário, velocidade, distrações, botão de WhatsApp escondido ou quebrado.
3. Liste as lacunas de confiança: provas (depoimentos, nota no MEC, credenciamento), clareza sobre preço, bolsa ou condições e sobre o próximo passo depois da inscrição.
4. Ordene os problemas pelo impacto provável.
5. Escreva a correção para os 3 primeiros.

Saída: tabela do raio-x e as 3 principais correções

Verificações antes de terminar:
- Marca de evidência ou hipótese em cada problema
- Correções específicas
