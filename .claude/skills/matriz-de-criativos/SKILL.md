# Montar a matriz de criativos

Propósito: Organizar os criativos de anúncio em variações testáveis, uma variável por vez.

Passos:
1. Liste os conceitos (ângulos) aprovados para o curso.
2. Para cada conceito, defina os formatos: vídeo curto vertical, imagem estática, carrossel.
3. Escreva de 2 a 3 ganchos por conceito (a primeira frase ou os 3 primeiros segundos).
4. Cruze conceito x formato x gancho e escolha só as combinações que cabem na verba de teste.
5. Dê a cada variação um nome padrão (conceito_formato_gancho_v1) e diga qual variável ela testa.
6. Defina o critério de vencedor (CPL e custo por matrícula contra a meta) e o volume mínimo antes de decidir.

Saída: Matriz de criativos com nome, conceito, formato, gancho, variável testada e critério de vencedor.

Verificações antes de terminar:
- Cada teste muda uma variável só
- Todo depoimento, imagem de pessoa, preço ou bolsa está marcado para aprovação
- Nenhum criativo promete emprego, salário ou aprovação
