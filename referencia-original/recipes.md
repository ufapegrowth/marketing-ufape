# Task recipes

## Task recipe 01 - Five-minute competitor snapshot

```
Use my Marketing Context File. Look at [competitor URL]. In a table give me their main promise, audience, offer, proof and latest campaign, then one gap I could use this week. Mark anything you could not verify.
```

## Task recipe 02 - One-line positioning test

```
Use my Marketing Context File. Write 5 versions of my positioning in one line each, for my primary ICP, against my main alternative. Score each for clarity and proof and tell me which to test first.
```

## Task recipe 03 - Quick page intent check

```
Use my Marketing Context File. Here is my page and its target keyword: [paste]. Tell me in 5 bullets whether the page matches search intent, what is missing and the new title and intro I should use.
```

## Task recipe 04 - Article outline in one go

```
Use my Marketing Context File. Topic: [topic]. Give me the reader, the one takeaway, 3 headline options and a section outline with one example per section. Keep it to one screen.
```

## Task recipe 05 - Story to post

```
Use my Marketing Context File. Here is something that happened this week: [story]. Turn it into one post with a strong first line, short lines, one lesson and two alternative first lines.
```

## Task recipe 06 - Ten lead magnet ideas

```
Use my Marketing Context File. Give me 10 lead magnet ideas for my primary ICP that solve one urgent problem in under 30 minutes. Score each on value, speed and link to my offer.
```

## Task recipe 07 - Rescue a flat email

```
Use my Marketing Context File. Here is an email that underperformed and its numbers: [paste]. Tell me the 3 most likely reasons and rewrite the subject line, hook and call to action.
```

## Task recipe 08 - Five-second test

```
Use my Marketing Context File. Here is my page hero: [paste]. Tell me what a first-time visitor would think it is, who it is for and what to do. Then rewrite the headline and subhead to fix any gap.
```

## Task recipe 09 - Three questions for my data

```
Use my Marketing Context File. Here are my exports: [paste or attach]. Answer: what grew, what shrank, and what should I do more of next month. Show the numbers behind each answer.
```

## Task recipe 10 - Find my bottleneck

```
Use my Marketing Context File. Here is how we produce content today: [describe]. Map the steps, name the bottleneck and redesign the flow with agent steps and human approvals.
```
