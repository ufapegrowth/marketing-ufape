# Write a 90-day marketing plan

Purpose: Turn one goal into 12 weeks of clear outputs.

Steps:
1. State the goal and the metric.
2. Pick audience, offer and up to 3 channels.
3. Split into three 30-day blocks with a theme each.
4. List weekly outputs and owners.
5. Set the weekly review questions.

Output: 12-week plan table

Checks before you finish:
- No week has more work than the capacity stated
- Each week has an owner
