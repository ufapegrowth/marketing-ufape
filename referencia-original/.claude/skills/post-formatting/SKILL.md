# Format a post for skimming

Purpose: Make any post easy to read on a phone.

Steps:
1. Put the hook alone on line 1.
2. Break into short lines with white space.
3. One idea per line or list item.
4. End with a clear point or question.
5. Check it reads well in the first 3 lines.

Output: Formatted post

Checks before you finish:
- No paragraph over 3 lines
- The first 3 lines make sense alone
