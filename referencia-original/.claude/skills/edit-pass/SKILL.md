# Run a three-pass edit

Purpose: Make any draft clearer and tighter in a repeatable way.

Steps:
1. Pass 1 structure: does every section earn its place?
2. Pass 2 clarity: shorten sentences, cut filler, use concrete words.
3. Pass 3 proof: check facts, sources and claims.
4. Read the intro and ending aloud.
5. Write the change log.

Output: Edited draft plus change log

Checks before you finish:
- No meaning changed without a note
- All claims sourced or removed
