# Build the knowledge index

Purpose: Help every agent find the right file first time.

Steps:
1. List the folders and key files.
2. Write one line on what each contains.
3. Name the agent or person who owns it.
4. Add the last updated date.
5. Save as knowledge/INDEX.md.

Output: INDEX.md

Checks before you finish:
- Every key file listed
- Owners named
