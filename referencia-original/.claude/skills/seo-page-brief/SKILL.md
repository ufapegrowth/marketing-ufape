# Write an SEO page brief

Purpose: Give a writer everything to match intent and outrank weak pages.

Steps:
1. Read the top results for the keyword and note their angle and gaps.
2. Define intent and the reader's question.
3. Outline headings and subtopics to cover.
4. Add internal links in and out.
5. Write the title and description options.

Output: SEO page brief ready for content-brief or longform-content

Checks before you finish:
- Outline covers what top results miss
- Internal links listed
