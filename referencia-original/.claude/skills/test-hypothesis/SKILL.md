# Write a test hypothesis

Purpose: Make every test teach you something.

Steps:
1. Describe the change.
2. Predict the effect on one metric.
3. Explain why you expect it.
4. Set the minimum run time.
5. Decide what you will do if it wins or loses.

Output: Hypothesis card

Checks before you finish:
- One change per test
- Decision rule written before the test
