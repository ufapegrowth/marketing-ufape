# Write an insight memo

Purpose: Turn data into decisions anyone can read in 2 minutes.

Steps:
1. State the question.
2. Show the data that answers it.
3. Explain the insight in one sentence.
4. Recommend one action.
5. List caveats.

Output: One-page insight memo

Checks before you finish:
- Data shown, not just described
- Caveats listed
