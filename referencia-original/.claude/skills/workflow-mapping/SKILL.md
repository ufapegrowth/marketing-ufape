# Map a marketing workflow

Purpose: Make recurring work run the same way every time.

Steps:
1. List each step from request to published.
2. Name the owner, input and output of each step.
3. Mark agent steps and human approval steps.
4. Remove steps that add no value.
5. Write the checklist.

Output: Workflow map plus checklist

Checks before you finish:
- Human approval before anything public
- Every step has an owner
