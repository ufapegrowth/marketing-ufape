# Write a campaign brief

Purpose: Give every agent the same picture of a campaign.

Steps:
1. State goal, audience, offer and message.
2. List channels and their role.
3. Lay out the timeline and assets.
4. Set targets and checkpoints.
5. Name approvals needed.

Output: Campaign brief

Checks before you finish:
- Targets are written before launch
- Every asset has an owner
