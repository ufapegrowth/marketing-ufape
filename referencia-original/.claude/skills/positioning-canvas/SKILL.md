# Fill a positioning canvas

Purpose: Find the frame where your value is obvious to the right buyer.

Steps:
1. List real alternatives, including doing nothing.
2. List your unique attributes.
3. Turn each attribute into value for the ICP.
4. Pick the market frame that makes the value obvious.
5. Write the statement and test it on 3 real customer stories.

Output: Completed canvas plus positioning statement

Checks before you finish:
- Every attribute has proof
- The statement fits on one line
