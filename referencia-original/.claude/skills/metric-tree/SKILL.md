# Build a marketing metric tree

Purpose: Connect daily activity to the business goal.

Steps:
1. Put the business goal at the top.
2. Break it into the marketing outcomes that drive it.
3. Break each outcome into leading indicators.
4. Name the source for each metric.
5. Mark the 5 metrics you review weekly.

Output: Metric tree plus weekly 5

Checks before you finish:
- Every metric has a source
- Weekly 5 includes leading and lagging metrics
