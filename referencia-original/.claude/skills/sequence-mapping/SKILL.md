# Map an email sequence

Purpose: Plan a sequence where every email has one job.

Steps:
1. Define the trigger and the end goal.
2. List 5 to 7 touches and the job of each.
3. Set timing between touches.
4. Write exit rules.
5. Note the tags or data needed.

Output: Sequence map

Checks before you finish:
- Each email has one call to action
- Exit rules defined
