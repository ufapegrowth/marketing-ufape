# Cluster keywords into topics

Purpose: Turn a long keyword list into pillar and support pages.

Steps:
1. Remove duplicates and off-topic terms.
2. Group by shared intent and meaning.
3. Name each cluster and choose a pillar keyword.
4. Assign support keywords to pages.
5. Mark existing pages against each cluster.

Output: Cluster table: cluster, pillar, support keywords, page status

Checks before you finish:
- One primary keyword per page
- No cluster mixes buy and learn intent
