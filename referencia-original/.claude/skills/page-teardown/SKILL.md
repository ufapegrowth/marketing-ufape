# Tear down a landing page

Purpose: Find what stops visitors from taking action.

Steps:
1. Run the 5-second test on the hero.
2. List friction points: form, speed, distractions.
3. List trust gaps: proof, guarantees, clarity on price or next step.
4. Rank issues by likely impact.
5. Write the fix for the top 3.

Output: Teardown table plus top 3 fixes

Checks before you finish:
- Evidence or hypothesis label on every issue
- Fixes are specific
