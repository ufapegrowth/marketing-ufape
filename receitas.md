# Receitas rápidas

Prompts de uma tacada só para ganhos rápidos. Cole no Claude Code e troque o que está entre colchetes. Todas assumem que contexto/ufape-geral.md e o contexto da linha estão preenchidos.

## Receita 01: Raio-x de concorrente em cinco minutos

```
Use o contexto da Ufape e da linha [graduacao | pos | livres]. Veja [URL da instituição concorrente]. Em uma tabela, me dê a promessa principal, o público, os cursos e preços que aparecem, as provas que usam e a campanha mais recente, e depois uma brecha que eu posso usar esta semana. Marque tudo que você não conseguiu verificar.
```

## Receita 02: Teste de posicionamento em uma linha

```
Use o contexto da Ufape e da linha [linha]. Escreva 5 versões do nosso posicionamento, uma linha cada, para a persona principal, contra a principal alternativa dela. Dê nota de clareza e de prova para cada uma e diga qual testar primeiro.
```

## Receita 03: Checagem rápida de intenção de busca

```
Use o contexto da Ufape. Aqui está a página do curso e a palavra-chave dela: [colar]. Em 5 tópicos, diga se a página responde à intenção de busca, o que falta e qual título e introdução devo usar. Dados de curso só do catálogo.
```

## Receita 04: Estrutura de artigo de uma vez

```
Use o contexto da Ufape e da linha [linha]. Tema: [tema, ex.: "MBA ou especialização: qual escolher"]. Me dê o leitor, a mensagem principal, 3 opções de título e a estrutura de seções com um exemplo por seção. Cabe em uma tela.
```

## Receita 05: História vira post

```
Use o contexto da Ufape. Isto aconteceu esta semana: [história real, com autorização se envolver aluno ou professor]. Transforme em um post com primeira linha forte, frases curtas, uma lição e duas opções alternativas de primeira linha.
```

## Receita 06: Dez ideias de isca digital

```
Use o contexto da Ufape e da linha [linha]. Me dê 10 ideias de isca digital para a persona principal que resolvam um problema urgente em menos de 30 minutos (ex.: teste vocacional, simulado, aula aberta). Dê nota de valor, rapidez e ligação com o curso.
```

## Receita 07: Resgate de mensagem que não performou

```
Use o contexto da Ufape. Aqui está um e-mail ou disparo de WhatsApp que performou mal e os números dele: [colar]. Diga os 3 motivos mais prováveis e reescreva o assunto ou a primeira linha, o gancho e a chamada para ação.
```

## Receita 08: Teste dos cinco segundos

```
Use o contexto da Ufape. Aqui está o topo da página do curso: [colar]. Diga o que um visitante de primeira vez entenderia que é, para quem é e o que fazer. Depois reescreva o título e o subtítulo para fechar qualquer lacuna.
```

## Receita 09: Três perguntas para os meus dados

```
Use o contexto da Ufape. Aqui estão as exportações: [colar ou anexar]. Responda: o que cresceu, o que caiu e o que devo fazer mais no mês que vem, separado por linha (Graduação, Pós, Livres). Mostre os números de cada resposta.
```

## Receita 10: Ache meu gargalo

```
Use o contexto da Ufape. É assim que produzimos conteúdo hoje: [descrever, do pedido do coordenador até a publicação]. Mapeie as etapas, aponte o gargalo e redesenhe o fluxo com etapas de agente e aprovações humanas.
```
